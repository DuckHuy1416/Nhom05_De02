# Mô hình đã huấn luyện

Mặc định không đưa trọng số lên Git; giữ `.gitkeep` và tài liệu này.
Gói nộp cuối kỳ phải kèm file `.keras` hoặc link tải truy cập được.
TV4 ghi tên file, mã lớp theo đúng thứ tự, phiên bản TensorFlow/Keras,
cách tiền xử lý, nguồn dữ liệu, giấy phép và checksum khi có mô hình thật.
TV5 kiểm tra tải/nạp được mô hình trước khi đóng gói. Hiện chưa có mô hình.
